プライバシーポリシー

NAGU-GROOVE Rhythm Project ／ 2026年10月5日 制定

NAGUWAVE(以下「運営」)は、ゲーム「NAGU-GROOVE Rhythm Project」(以下「本ゲーム」)で扱うプレイヤーの情報について、次のとおり取り扱います。

1. 集める情報

  • ログインの情報:Google アカウントでログインしたときに、Google から受け取るアカウントの識別番号など(認証には Firebase Authentication を使っています)
  • プレイヤーが入力・設定した情報:プレイヤー名、プロフィール画像、付けている称号、パートナーのキャラクター
  • プレイの記録:レベル、ナグコイン、持っているキャラクターやアイテム、クリア回数・ランクなどの記録、ミッション・実績の進み具合、ログイン日数
  • フレンド機能の情報:フレンドコード、フレンド申請とフレンド関係、送ったメッセージ、ブロックの設定
  • 送ってもらった内容:アンケート(SURVEY)と通報の内容
  • 端末の中に保存する情報:音量などの設定、お知らせやメッセージを読んだかどうかの記録(お使いのブラウザの中に保存され、運営には送られません)

2. 使う目的

  • セーブデータを保存し、別の端末でも続きから遊べるようにするため
  • フレンド機能やお知らせなど、ゲームの機能を提供するため
  • 不正行為や迷惑行為を防ぎ、通報に対応するため
  • 不具合の修正や、ゲームをよくするための参考にするため

3. ほかのプレイヤーに見える情報

ログインしているほかのプレイヤーには、次の情報が見えることがあります:プレイヤー名、プロフィール画像、称号、プレイヤーレベル、パートナーのキャラクター(レベル・凸)、クリア回数などの記録、フレンドコード。
メッセージは、送った相手のフレンドにだけ見えます。

4. ほかの人に渡すこと

運営は、法律で求められた場合などを除いて、プレイヤーの情報を本人の同意なくほかの人や会社に渡すことはありません。

5. 使っている外部サービス

  • Firebase(Google LLC):ログインとデータの保存に使っています。データは Google のサーバーに保存されます。
  • GitHub Pages(GitHub, Inc.):本ゲームの公開に使っています。アクセスの記録が GitHub によって残ることがあります。
  • OFUSE:応援(寄付)のページです。応援するときの情報は、OFUSE のプライバシーポリシーに従って扱われます。
  • X(旧 Twitter):リザルト画面の「SHARE」から投稿するときに使います。

6. データの削除

アカウントとセーブデータの削除をご希望の場合は、下のお問い合わせ先からご連絡ください。ご本人の確認ができたあと、削除します。(ゲーム内から削除できる機能も、準備ができしだい追加します)

7. 安全のために

運営は、集めた情報が漏れたり、なくなったりしないよう、アクセスできる範囲を必要なものに限るなど、適切に管理します。

8. 未成年の方へ

未成年の方は、保護者の方と一緒にこのポリシーを読み、同意を得たうえで遊んでください。

9. このポリシーの変更

運営は、必要に応じてこのポリシーを変更することがあります。大きな変更は、ゲーム内のお知らせなどでお伝えします。

10. お問い合わせ

  • ゲーム内の「SURVEY」(アンケート)
